The codes I develop are open source, so anyone can run them, check them and build on them.

MATINS

MAgneto-Thermal evolution of Isolated Neutron Stars

A 3D code that follows how the magnetic field and the temperature of a neutron star evolve together over a million years, on a cubed-sphere grid with realistic microphysics.

  • Fortran 90
  • OpenMP
  • GPL-3.0

GitHub Project page The science

If you use MATINS, please cite

  • Dehman et al. 2023, MNRAS 518, 1222 (magnetic field) DOI
  • Ascenzi et al. 2024, MNRAS 533, 201 (thermal evolution) DOI
